## :dart: O guia para alavancar a sua carreira

> Laravel é o framework PHP mais usado do mundo: sintaxe elegante, ORM (Eloquent) poderoso, sistema de rotas, filas, autenticação e um ecossistema gigante (Forge, Vapor, Nova, Livewire, Filament) que resolve praticamente qualquer necessidade de uma aplicação web. É a base de produtos brasileiros e internacionais e a porta de entrada mais comum para quem já sabe PHP e quer construir sistemas robustos rápido. Este guia reúne roadmap, documentação oficial, cursos gratuitos e pagos, livros, canais, ferramentas do ecossistema e um capítulo sobre usar IA na prática com Laravel — tudo verificado, com prioridade para conteúdo gratuito e em português.

## 🗺️ Roadmap
- [roadmap.sh — PHP Roadmap](https://roadmap.sh/php) — Guia da comunidade sobre o caminho de PHP até back-end, com Laravel como o framework mais recomendado no trecho de "frameworks".
- [Laravel release notes (documentação oficial)](https://laravel.com/docs/13.x/releases) — Histórico completo de versões, do 1.0 à atual (13.x), com o calendário de suporte de cada uma.
- [Laravel upgrade guide](https://laravel.com/docs/13.x/upgrade) — Guia oficial passo a passo para migrar um projeto entre versões do framework.
- [laravel/framework (código-fonte no GitHub)](https://github.com/laravel/framework) — Repositório oficial do framework — leia issues e PRs para entender como ele evolui.
- [Request Lifecycle (documentação oficial)](https://laravel.com/docs/13.x/lifecycle) — Como uma requisição HTTP percorre o framework, do `public/index.php` até a resposta — essencial para entender a arquitetura do Laravel.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Fundamentos de PHP** — variáveis, funções, orientação a objetos, Composer. Laravel pressupõe PHP intermediário.
2. **Primeiro projeto** — instalação via Composer/Laravel Installer, estrutura de pastas, servidor de desenvolvimento (`php artisan serve`).
3. **Rotas, controllers e Blade** — `routes/web.php`, controllers, o motor de templates Blade.
4. **Eloquent e banco de dados** — models, migrations, relacionamentos, query builder.
5. **Autenticação e validação** — starter kits (Breeze/Jetstream), `FormRequest`, regras de validação.
6. **Testes** — Pest ou PHPUnit, testes de feature e unitários.
7. **APIs** — API Resources, Sanctum para autenticação de SPA/mobile.
8. **Filas, cache e eventos** — jobs assíncronos, cache, broadcasting em tempo real (Reverb).
9. **Produção** — deploy (Forge, Vapor, Laravel Cloud, Docker/Sail), variáveis de ambiente, monitoramento (Pulse, Telescope).
10. **Especialização** — Livewire/Inertia para front-end reativo, Filament para painéis administrativos, Octane para performance.

## 🚀 Por onde começar
1. **Instale o PHP e o Composer**, depois crie seu primeiro projeto com o [Laravel Installer](https://laravel.com/docs/13.x/installation) — a própria documentação já traz alternativas com Docker (Sail) e sem instalar nada localmente.
2. **Leia a introdução da documentação oficial** — [Installation](https://laravel.com/docs/13.x/installation) e [Configuration](https://laravel.com/docs/13.x/configuration) — para entender a estrutura inicial de um projeto.
3. **Faça o Laravel Bootcamp** — [bootcamp.laravel.com](https://bootcamp.laravel.com/) — tutorial oficial que constrói uma aplicação de chat em tempo real do zero, com Livewire ou Vue/React via Inertia.
4. **Assista a um curso em vídeo em português** em paralelo à leitura da documentação — veja a seção [🔤 Sites e cursos](#-sites-e-cursos-para-aprender-laravel) abaixo.
5. **Entenda a estrutura de diretórios oficial** — [Directory Structure](https://laravel.com/docs/13.x/structure) — o que cada pasta do projeto padrão faz.
6. **Escolha um starter kit de autenticação** — [Starter Kits](https://laravel.com/docs/13.x/starter-kits) — Breeze, Jetstream ou os kits com React/Vue/Livewire já prontos.
7. **Aprenda o Eloquent ORM** — [Eloquent: Getting Started](https://laravel.com/docs/13.x/eloquent) — a forma como o Laravel conversa com o banco de dados.
8. **Publique um projeto** — planos gratuitos como Railway, Render ou o novo [Laravel Cloud](https://laravel.com/cloud) funcionam bem para começar.

Seu primeiro projeto em poucos comandos:

```bash
composer create-project laravel/laravel meu-projeto
cd meu-projeto
php artisan serve
```

## 🛠️ Ferramentas
### Ecossistema oficial
- [Laravel Forge](https://forge.laravel.com/) — Provisionamento e deploy automatizado de servidores para aplicações Laravel — serviço pago.
- [Laravel Vapor](https://vapor.laravel.com/) — Plataforma serverless oficial para rodar Laravel na AWS — serviço pago.
- [Laravel Cloud](https://laravel.com/cloud) — Plataforma de hospedagem gerenciada mais recente da equipe do Laravel, lançada em 2024 — serviço pago com camada gratuita para testes.
- [Laravel Herd](https://herd.laravel.com/) — Ambiente de desenvolvimento local nativo (macOS e Windows) com PHP, Nginx e mais, criado pela equipe do Laravel.
- [Laravel Nova](https://nova.laravel.com/) — Painel administrativo oficial, elegante e configurável via código — pago.
- [Laravel Sail](https://laravel.com/docs/13.x/sail) — Ambiente de desenvolvimento local baseado em Docker, com configuração mínima.

### Front-end e interatividade
- [Laravel Livewire](https://livewire.laravel.com/) — Interfaces reativas sem sair do PHP, sem precisar escrever uma API separada.
- [Inertia.js](https://inertiajs.com/) — Conecta o back-end Laravel a front-ends em Vue, React ou Svelte sem construir uma API REST.
- [Laravel Breeze](https://github.com/laravel/breeze) — Starter kit minimalista de autenticação (Blade, Livewire, React ou Vue).
- [Laravel Jetstream](https://jetstream.laravel.com/) — Starter kit de autenticação mais robusto, com times, 2FA e API tokens.
- [Filament](https://filamentphp.com/) — Painel administrativo e construtor de formulários open source, muito popular na comunidade.

### Produtividade, testes e depuração
- [Pest PHP](https://pestphp.com/) — Framework de testes com sintaxe elegante, hoje o padrão recomendado para testar aplicações Laravel.
- [Laravel Pint](https://laravel.com/docs/13.x/pint) — Formatador de código PHP opinativo, criado pela equipe do Laravel.
- [Laravel Telescope](https://laravel.com/docs/13.x/telescope) — Painel de depuração com requests, queries, jobs e exceptions da aplicação em desenvolvimento.
- [Laravel Pulse](https://laravel.com/docs/13.x/pulse) — Monitoramento de performance e uso da aplicação em produção, em tempo real.
- [Laravel Debugbar (fruitcake, antigo barryvdh)](https://github.com/barryvdh/laravel-debugbar) — Barra de depuração com queries SQL, tempo de resposta e mais, direto no navegador.
- [Laravel IDE Helper](https://github.com/barryvdh/laravel-ide-helper) — Gera anotações para autocompletar Eloquent e facades no editor.
- [Spatie laravel-permission](https://github.com/spatie/laravel-permission) — Gerenciamento de papéis e permissões para Eloquent, um dos pacotes mais usados do ecossistema.
- [Packagist](https://packagist.org/) — O repositório oficial de pacotes PHP/Composer, onde vive praticamente todo o ecossistema Laravel.

### Filas, APIs e produção
- [Laravel Octane](https://laravel.com/docs/13.x/octane) — Acelera a aplicação servindo-a com servidores de alta performance (Swoole, RoadRunner, FrankenPHP).
- [Laravel Reverb](https://laravel.com/docs/13.x/reverb) — Servidor de WebSockets oficial, para funcionalidades em tempo real sem depender de serviços de terceiros.
- [Laravel Sanctum](https://laravel.com/docs/13.x/sanctum) — Autenticação leve para SPAs, aplicações mobile e APIs simples baseadas em token.
- [Laravel Cashier (Stripe)](https://laravel.com/docs/13.x/billing) — Camada expressiva para assinaturas e cobrança recorrente com o Stripe.
- [Laravel Scout](https://laravel.com/docs/13.x/scout) — Solução simples para adicionar busca em texto completo aos models Eloquent.
- [Laravel Socialite](https://laravel.com/docs/13.x/socialite) — Autenticação OAuth com provedores como GitHub, Google e Facebook, com poucas linhas de código.

## 🤖 IA na prática
Laravel é maduro, muito bem documentado e a própria equipe do framework investiu pesado em ferramentas de IA em 2024–2026 (AI SDK, MCP, Boost). Isso torna os assistentes de código muito bons para gerar boilerplate (models, migrations, controllers, testes), mas o Eloquent e as convenções do framework ainda têm detalhes específicos que a IA erra, principalmente ao misturar versões diferentes do Laravel.

**Para aprender**
- Peça para a IA explicar um erro de migration ou de relacionamento Eloquent (`SQLSTATE`, `BelongsToMany` mal configurado) e sugerir como corrigir sem perder dados.
- Peça exercícios com testes usando Pest sobre o tópico que está estudando: você escreve a solução, o teste diz se passou.
- Peça para transformar uma query solta em Eloquent num Query Builder mais performático (ou vice-versa) e explicar o trade-off.
- Use a IA para revisar o relacionamento entre seus models antes de rodar `php artisan migrate`.

**Para trabalhar**
- Use GitHub Copilot, Cursor ou Claude Code para gerar controllers, form requests e testes Pest a partir dos models, e explicar queries Eloquent complexas.
- Experimente o [Laravel Boost](https://laravel.com/docs/13.x/boost), pacote oficial que dá ao seu assistente de IA contexto real sobre as versões instaladas do Laravel e dos pacotes do projeto — reduz alucinação de API.
- Use o [Laravel MCP](https://laravel.com/docs/13.x/mcp) para expor ferramentas e dados da sua aplicação a agentes de IA de forma padronizada.
- Depois de aceitar uma sugestão que mexe no banco, **leia** a migration gerada antes de rodar — IA às vezes cria migrations destrutivas (`dropColumn` sem necessidade).
- [GitHub Copilot](https://github.com/features/copilot) — Autocomplete e chat com IA no editor; gratuito para estudantes e com plano free.
- [Cursor](https://cursor.com/) — Editor baseado no VS Code com IA integrada ao fluxo de trabalho.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: escreve testes Pest, revisa migrations e explica queries Eloquent.

**Limites e boas práticas**
- IA **inventa métodos do Eloquent** que não existem na versão instalada — confira sempre na documentação oficial da versão em uso (`php artisan --version`).
- Desconfie de código que monta SQL "na mão" com concatenação de strings em vez de usar o Query Builder/Eloquent — é o padrão de SQL injection mais repetido por IA.
- Nunca aceite sugestões que exponham `APP_KEY`, credenciais de banco no `.env` versionado, ou desativem o CSRF em rotas que não deveriam.
- Migrations geradas por IA precisam ser lidas por um humano antes de rodar em produção — reverter uma migration aplicada num banco com dados reais pode ser destrutivo.
